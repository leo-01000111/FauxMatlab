Tour

A tour of Evans

Three workspaces, one live model. What follows is what each part does and how to drive it.

Three workspaces

The workspaces sit on a rail down the left, on Ctrl+1, Ctrl+2 and Ctrl+3. Switching keeps everything alive, so a running console session, a half-built diagram and a configured analysis are all still there when you come back.

A context bar across the top of Analyse shows what is loaded and whether it works:

G(s)  = 4 / (s² + 1.2s + 4)
K₂(s) = 2 · (s + 0.5) / s     ● stable    PM 60.0°   GM 11.9 dB   [Edit model ▾]

It gives the factored transfer functions, an internal-stability verdict and the headline margins. An undefined quantity shows as an em dash with a tooltip explaining why, so a phase margin that does not exist reads differently from nan. The architecture diagram and block editor open in a panel behind Ctrl+\.

The pane grid

The analysis grid holds one, two or four panes, with seventeen contents each, all reading the same live architecture, so one edit moves every visible view at once. A fresh 2×2 opens on step response, Bode, root locus and metrics, the four views you want side by side when tuning a controller.

Each pane remembers which system it shows (plant, open loop, closed loop, sensitivity) when you change what it draws, so the plant's Bode plot becomes the plant's step response. The bigger workflows are pane contents too: the time analysis with its signal pairs and parameter sweep, and the frequency analysis with templates and overlays.

Every plot reads out the point under the mouse: ω and |L| on a Bode plot, t and y on a step, ω on a Nyquist curve, K on a root locus. Phase axes tick at multiples of 90° (45° zoomed in) and dB axes at multiples of 20. Margins, crossover, peak and settling are marked by default. Bode plots carry the classical straight-line asymptotes, and hovering one gives its slope and end points.

The minimum-phase split is chapter 4's G(s) = Gallpass(s)·Gmp(s). Right-half-plane zeros are mirrored into the left half-plane, Gallpass carries all the extra phase lag at unit gain, and |G| = |Gmp| everywhere. At the prompt it is Gap, Gmp = mpsplit(G).

The command window

@@n_commands@@ MATLAB-shaped commands in ten groups (tf, feedback, step, bode, margin, stepinfo, rlocus, lqr, place, c2d, pidtune and more), with a workspace browser, history, tab completion and a script editor. The command reference lists every one.

s is the Laplace variable, so G = 1/(s**2 + 2*s + 1) works. The console shares live references with the GUI: setting a block at the prompt changes what every pane analyses.

G = 1/(s**2 + 2*s + 1)
T = feedback(G, 1)
stepinfo(T)
bode(G)

The prompt is Python: commas between list elements, 0-based indexing, ** for powers. The Script tab is where MATLAB runs as written.

Scripts

Paste a .m file into the Script tab and it runs as MATLAB. Auto picks the language from the text, and the selector beside Run overrides it. MATLAB compatibility lists what scripts can use.

Run starts from a clean slate. It clears the transcript and the previous run's figures first, and offers to save any figures that were never saved, as figure_1.png, figure_2.png and so on. Lines typed at the prompt still append.

The editor highlights MATLAB, numbers its lines and completes names on Tab (variables, builtins, .m files in the folder). %% splits it into sections: Ctrl+Enter runs the one under the cursor, Ctrl+Shift+Enter runs it and moves on.

Click the gutter for a breakpoint. F5 runs or continues, F10 steps and F11 steps into your functions; while paused, the prompt (K>>) and the workspace see the paused scope. Stop, Shift+F5 or Ctrl+C interrupts anything, while true included.

Live scripts

The Live tab holds code cells and text cells, and output and figures stay under the cell that made them. Text takes $…$ and $$…$$ LaTeX, drawn in place, and {{Kp}} shows a workspace value.

It opens MATLAB's .mlx files and plain-text live .m files, and saves the latter. Export report writes a .tex with its figures and builds the PDF if a TeX engine (tectonic, MiKTeX, TeX Live) is installed, or an HTML page if not.

Figures

Figures sit under the command window. Split shows two side by side, older on the left. Undock moves one into a window of its own, where it keeps panning, zooming and reading out, and Dock or closing that window brings it back. Save… or a right-click writes PNG, SVG or the data as CSV.

The History tab beside the workspace keeps commands between sessions, and File ▸ Open recent lists the last scripts and models.

The simulator

The Model workspace is a block-diagram simulator: @@n_blocks@@ block types (see the block reference), hierarchical subsystems, a drag-and-drop canvas with undo, RK4, RK45 and Euler solvers, scopes, and a properties inspector that leaves the diagram visible. linearize() pulls a state-space model out of a nonlinear diagram.

  • Wire two blocks by dragging between ports, or by clicking one and then the other.
  • Drag with the middle mouse button to pan.
  • A dragged block snaps into line with its neighbours' centres and edges; hold Alt to place it freely.
  • The scope opens on r.out and G.out.
  • Once the blocks are placed, the palette folds away to a strip (Ctrl+B).

A PID block's Tune…, from the right-click menu or the inspector, opens a small tuner on the plant that block sees, linearised from the diagram with the loop cut at the PID, and writes the gains back as one undoable step.

Discrete blocks sample and hold: they read their inputs at a sample hit and hold their outputs until the next one, so a 50 Hz controller changes its output 50 times a second, and a discrete block breaks an algebraic loop the way it does in real hardware.

The design apps

Three apps dock beside the analysis they edit, opened from the Apps menu or the prompt:

LTI Viewer · ltiview
Any set of systems, eight response types, and a right-click menu to add characteristics. It only offers the ones that mean something for the response on screen; a rise time has nowhere to go on a Nyquist plot.
Control System Designer · sisotool
Drag a closed-loop pole along the root locus and the Bode plot and step response follow. You can also ask for the gain that gives ζ = 0.5, or 16% overshoot.
PID Tuner · pidtuner
Response time and transient behaviour on two sliders, with the plant, the current loop and the tuned loop overlaid (K₁ and H included).

The PID tuner does not search for gains. At the target crossover the controller's required magnitude and phase are both fixed, so a PI's two parameters follow directly and a PID spends its third on the classical Ti = 4·Td. The achieved margin is therefore exact: margin(C·G) returns the requested ωc and φm to 1e-14. When a structure cannot meet a target, the tuner refuses and gives the reason.

Snapshots and layout

A snapshot bar above the analysis area saves the whole architecture under a name and restores it from anywhere. Compare sends every stored design to the LTI Viewer at once.

Window geometry, workspace, dock layout and pane arrangement are remembered between runs, and View ▸ Reset layout puts them back. View ▸ Theme picks Day, Night or the system setting. The window fits a 1280 × 720 screen and is tested at 1366 × 768 and 1920 × 1080 as well.

Lessons

The Lessons menu loads one worked example per chapter, and each one checks its own claims against the model on screen: change the plant and the ticks turn into crosses. The lessons page has all @@n_lessons@@, with every claim measured.
