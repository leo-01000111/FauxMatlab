Evans, a control-systems workbench

Classical and modern control, a block-diagram simulator and a MATLAB-shaped command window in one desktop application. It covers the part of MATLAB, Simulink and the Control System Toolbox that two control courses use: CLACO (classical, frequency domain) and DYBAC (modern, state space). Every number it shows can be traced back to something exact.

What it looks like

Three workspaces sit on a rail down the left: Analyse for the current control system, Model for the block-diagram simulator and Console for the command window, scripts and figures. View ▸ Theme picks Day, Night or the system setting.

What's in it

Analysis
One, two or four panes with seventeen contents each: step, Bode, Nyquist, Nichols, root locus, pole-zero map, margins, Routh and more, all reading the same live model.
Command window
@@n_commands@@ MATLAB-shaped commands such as tf, feedback, margin, rlocus, lqr, c2d and pidtune, with a workspace browser and history.
MATLAB scripts
The Script tab runs .m files as written, with a debugger. The Live tab opens .mlx live scripts and exports a report.
Simulator
@@n_blocks@@ block types, subsystems, RK4, RK45 and Euler solvers, scopes, and linearize() from a nonlinear diagram.
Design apps
LTI Viewer, Control System Designer (drag a pole along the root locus) and a PID Tuner whose margins are exact.
Lessons
One worked example per chapter. Each claim is measured from the loaded model, so a note that stops being true shows a cross.

Run it from source

On Windows, macOS or Linux, with Python 3.12 or newer:

git clone https://github.com/leo-01000111/evans.git
cd evans
python -m venv .venv
.venv\Scripts\activate          # Windows; elsewhere: source .venv/bin/activate
pip install -e ".[dev]"
python app.py

python app.py --check runs a headless self-test whose exit code is the number of failures. More on running from source

The name

Evans is named after Walter R. Evans, who invented the root locus. It was called FauxMatlab before version 0.9; models and settings saved under that name still open.
