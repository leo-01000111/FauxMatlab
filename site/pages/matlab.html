MATLAB compatibility

Running MATLAB scripts

The console prompt is Python, but the Script tab runs MATLAB scripts as written, and the Live tab opens MATLAB live scripts. This page lists what a script can use. It covers what two control courses need, not the whole MATLAB language.

The language

Paste a .m file into the Script tab and Evans translates it. Auto picks the language from the text, and the selector beside Run overrides it. A script can use:

  • matrix literals such as [1 -2 3], ^ and the ' transpose;
  • 1-based indexing with end, and a:b:c ranges;
  • if, for, while, switch and try blocks;
  • local functions, and function files in the script's folder, called the way MATLAB calls them, with cd, pwd and addpath;
  • cells, structs and struct arrays;
  • hold on, grid on and close all;
  • multiple outputs: [y, t] = step(G) returns MATLAB's outputs in MATLAB's order without plotting.

An error names the MATLAB line, never the generated Python.

Running and debugging

Run starts from a clean slate: it clears the transcript and the previous run's figures, and offers to save figures that were never saved. %% splits a script into sections; Ctrl+Enter runs the one under the cursor and Ctrl+Shift+Enter runs it and moves on.

Click the gutter for a breakpoint. F5 runs or continues, F10 steps and F11 steps into your functions. While paused, the K>> prompt and the workspace see the paused scope. Stop, Shift+F5 or Ctrl+C interrupts anything, while true included.

Live scripts

The Live tab opens MATLAB's .mlx files and plain-text live .m files, and saves the latter. Code cells keep their output and figures underneath; text cells take $…$ and $$…$$ LaTeX and {{Kp}} for a workspace value.

Export report writes a .tex with its figures and builds the PDF if a TeX engine (tectonic, MiKTeX, TeX Live) is installed, or an HTML page if not.

At the prompt

Lines typed at the console prompt are Python. The command names are MATLAB's, so a snippet usually needs only commas added: G = tf([1], [1, 2, 1]). Powers are **, indexing is 0-based, and s is the Laplace variable.
